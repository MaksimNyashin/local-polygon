Brief help
Make options:
    make build:
        Builds C++ files
        Deprecated (Now everything build automatically when needed)
    make gen:
        Generates tests using ./solutions/$main.$lang as main correct solution
        Uses ./generator.cpp and ./validator.cpp to generate and validate tests
        With generator strings from ./outer_files/generator_strings.txt
    make run:
        Runs main solution ./solutions/$main.$lang
        With ./solutions/in.txt as input file
        Outputs time of the run
    make invoke
        Invokes files from ./outer_files/invoke_solutions.txt
        Runs all generated tests
        Outputs everything using a nice table with colors
        TODO: catch MLs
    make freemaker:
        Outputs lines for test generation inside https://polygon.codeforcex.com/
    make help:
        Outputs this help message

outer_files:
    config.sh:
        main:
            The relative path of the main correct solution without the extension
            It is necessary to store solutions in the ./solutions folder
        lang:
            The programming language of the main correct solution
            This value must be equal to the extension of the main solution
            Only two languages are supported: "py" and "cpp"
        first_test_num:
            The number of the first generated test
        checker:
            The name of the checker from the ./checkers folder without the extension
            There are some standard checkers in the ./checker folder
            If needed ./checkers/checker.cpp can be modified (write checker.cpp to select custom checker)
        tl:
            Time Limit in milliseconds
            Not very precise
    cpp_build.txt:
        Add paths here to c++ files to build them using "make build" (deprecated)
        Paths are counted from the folder that contains the makefile
        Not more than one file in each line
        Line starting with "# " are commented out
        Must end with an empty line
    gen_strings.txt
        Add generator strings here to generate tests
        Not more than instruction in each line
        Line starting with "# " are commented out
        Must end with an empty line
        To set a group name write "--group=<group_name>" in a separate line before the first test of this group
            It will generate group "$ind<group_name>", where $ind is the number of the group
            This is done because polygon works not well with non-ordered group names and with dashes/underscores
    invoke_solutions.txt
        Add solution-filename stored in the ./solutions folder run them in "make invoke"
        After the solution-filename list all possible non-OK verdicts separated by "/":
            CE - compilation error (if appears then invocation of the solution is failed)
            RE - runtime error
            TL - time limit exceeded
            WA - wrong answer
        Not more than 1 solution in each line
        Line starting with "# " are commented out
        Must end with an empty line
